# 财务管理本科全套综合计算器（finance-calculator）

一个面向财务管理本科教学的**本地图形界面综合计算器**，同时保留命令行模式。覆盖资金时间价值、项目投资、资本成本、杠杆、资本结构、营运资金、成本管理、证券估值、财务分析、股利政策、期权基础和财务预算 12 个模块。

项目强调“**不仅给答案，还给完整解题步骤**”：每次计算都会展示公式、代入过程和结论，并自动写入 Excel 可直接打开的 `result.csv`。同时支持现金流时间轴、本量利图、杜邦瀑布图，图片统一保存到 `image/`。

## 5. 使用教程

### 5.1 图形界面（推荐）

双击 `启动财务计算器.bat`，或在终端执行 `python -m streamlit run app.py`。

操作流程：

1. 左侧选择模块（首页也提供 12 个模块入口卡片）；
2. 选择具体计算类型；
3. 在表单中填写参数，点击“开始计算”；
4. 查看 KPI 卡片、完整解题步骤、结果表、明细表和图表；
5. 点击“下载本次结果”，或在侧边栏下载全部历史结果；
6. 点击“运行本页示例”可一键载入当前类型的标准例题。

界面特点：

- 原生 Streamlit 主题，宽屏布局，适合电脑浏览器；
- WACC、公司价值、信用政策、作业成本等复杂数据可直接在表格中增删行；
- 每次计算自动追加到 `result.csv`；
- 表格、图片和下载按钮均在同一页面完成；
- 关闭启动窗口即可停止本地服务。

### 5.2 控制台主菜单

运行 `python main.py` 后，输入编号：

```text
 1. 模块1  资金时间价值
 2. 模块2  项目投资管理
 ...
12. 模块12 财务预算
13. 批量多组测算示例
14. 查看导出文件与运行环境
15. 公式与使用帮助
 0. 退出
```

进入模块后，再次选择具体功能或“一键例题演示”。输入 `0` 返回主菜单。

### 5.3 输入约定

| 类型 | 输入方式 | 示例 |
|---|---|---|
| 比率 | 按百分数输入，程序内部自动除以 100 | 年利率 8% → 输入 `8` |
| 折现率 | 非负百分数，最多 1000% | 输入 `10` 表示 10% |
| 股利增长率 | 可输入负数 | 下降 2% → 输入 `-2` |
| 期数 | 正整数 | 输入 `5` |
| 现金流量/序列 | 英文逗号分隔；中文逗号也可识别 | `-100000,30000,35000,40000` |
| 金额 | 正数或题目允许的负数 | `1000000` |
| 是否绘图 | 输入 `y` / `n` | 直接回车采用默认 |

金额单位由用户自行保持一致。同一道题中，建议全部使用“元”或全部使用“万元”，不要混用。

### 5.4 完整解题步骤

每次计算依次输出：

1. 已知参数；
2. 完整解题步骤（公式、代入、中间结果）；
3. 最终结果；
4. 表格（如有）；
5. 结论、风险提示与假设；
6. `result.csv` 导出位置。

例如项目投资评价会输出 NPV、IRR、PI、ANCF、静态/动态回收期，并给出分年现金流与累计折现表。

### 5.5 图片输出

图形保存在 `image/`：

- 现金流时间轴：`cash_flow_时间戳.png`
- 本量利图：`cvp_时间戳.png`
- 杜邦瀑布图：`dupont_waterfall_时间戳.png`

程序使用 Agg 后端，不弹窗，适合 VSCode、远程桌面和批量运行。中文字体优先使用微软雅黑/黑体，并自动关闭负号乱码。

### 5.6 CSV 导出

- 文件：项目根目录 `result.csv`
- 编码：`utf-8-sig`（带 BOM，Excel 双击不乱码）
- 字段：记录时间、模块、计算项目、输入参数、计算结论、备注
- 行为：每次计算追加一行，不覆盖历史结果
- 批量导出：`export.append_batch(results)` 或主菜单第 13 项

主菜单第 13 项会以 6%~14% 的五个折现率批量测算同一项目，一次性导出 5 行，便于 Excel 做敏感性分析图。

## 7. 全部财务管理公式清单

> 约定：`i` 为折现率/利率，`n` 为普通年金期数，`m` 为递延期数；`(P/F,i,n)` 为复利现值系数，`(P/A,i,n)` 为年金现值系数，`(F/A,i,n)` 为年金终值系数。程序内所有比率均以小数参与计算。

### 7.1 资金时间价值

1. 复利终值：`F = P × (F/P,i,n) = P × (1+i)^n`
2. 复利现值：`P = F × (P/F,i,n) = F ÷ (1+i)^n`
3. 普通年金终值：`F = A × (F/A,i,n) = A × [(1+i)^n-1]/i`
4. 普通年金现值：`P = A × (P/A,i,n) = A × [1-(1+i)^-n]/i`
5. 预付年金终值：`F = 普通年金终值 × (1+i)`
6. 预付年金现值：`P = 普通年金现值 × (1+i)`
7. 递延年金现值（第 m+1 期起连续支付 n 期）：`P = A × (P/A,i,n) × (P/F,i,m)`
8. 递延年金终值：`F = A × (F/A,i,n)`，递延期不影响终值
9. 永续年金现值：`P = A/i`；永续年金无终值
10. 内插法：`i ≈ i1 + NPV1/(NPV1-NPV2) × (i2-i1)`，要求 `NPV1` 与 `NPV2` 异号
11. 净现值（通用）：`NPV = Σ CF_t/(1+i)^t`，初始投资在 `t=0` 记为负数

### 7.2 项目投资管理

1. 净现值：`NPV = -初始投资 + Σ_{t=1}^n CF_t/(1+i)^t`
2. 内含收益率：使 `NPV(IRR)=0` 的折现率
3. 现值指数：`PI = 未来现金流入现值 ÷ 初始投资`
4. 年金净流量：`ANCF = NPV ÷ (P/A,i,n)`
5. 静态回收期：累计未折现现金流首次由负转正所需时间；不足一年按 `尚未回收额 ÷ 当年净现金流` 折算
6. 动态回收期：用折现现金流重复上述过程
7. 互斥方案，年限相同：选择 `NPV` 最大者
8. 互斥方案，年限不同：选择 `ANCF`（等额年金/EAA）最大者
9. 决策：`NPV>0`、`PI>1`、`IRR>必要报酬率` 时项目可行

### 7.3 资本成本

1. CAPM：`K = Rf + β × (Rm-Rf)`
2. 债务资本成本（一般模式）：`Kd = I × (1-T) / [L × (1-f)]`
3. 债务资本成本（贴现模式）：`筹资净额 = Σ[面值×票面利率×(1-T)/(1+Kd)^t] + 面值/(1+Kd)^n`
4. 普通股成本（股利增长模型）：`Ks = D1/[P0(1-f)] + g`，`D1=D0(1+g)`
5. 普通股成本（CAPM）：同 CAPM
6. 留存收益成本：`Ks = D1/P0 + g`（无筹资费率）
7. 加权平均资本成本：`WACC = Σ Wj × Kj`，`ΣWj=1`

### 7.4 杠杆原理

1. 边际贡献：`M = Q(P-V)`
2. 息税前利润：`EBIT = M-F`
3. 经营杠杆：`DOL = M/EBIT = Q(P-V)/[Q(P-V)-F]`
4. 财务杠杆：`DFL = EBIT/[EBIT-I-Dp/(1-T)]`
5. 总杠杆：`DTL = DOL × DFL = M/[EBIT-I-Dp/(1-T)]`
6. 销量变动传导：`EBIT 变动率 ≈ DOL × 销量变动率`，`EPS 变动率 ≈ DTL × 销量变动率`
7. 风险规律：DOL 越高经营风险越大；DFL 越高财务风险越大；DTL 叠加两类风险

### 7.5 资本结构

1. 每股收益：`EPS = [(EBIT-I)(1-T)-Dp]/N`
2. 无差别点：令两个方案 EPS 相等，解出 `EBIT*`
3. 决策：预期 EBIT 高于无差别点时，通常股数较少、负债较高的方案 EPS 更高；低于时权益融资更有利
4. 公司价值分析：`S = (EBIT-I)(1-T)/Ks`，`V = S+B`
5. 公司价值法 WACC：`WACC = Kd(1-T)×B/V + Ks×S/V`
6. 决策：选择公司价值 `V` 最大（通常 WACC 最低）的资本结构

### 7.6 营运资金管理

1. 现金存货模型：`C* = √(2TF/K)`
2. 相关总成本：`TC = T/C×F + C/2×K`
3. 最佳转换次数：`T/C*`
4. Miller-Orr 回归线：`R = L + [3Fσ²/(4i)]^(1/3)`
5. Miller-Orr 上限：`H = 3R - 2L`
6. 平均应收账款：`年销售额/360 × 平均收现期`
7. 应收账款机会成本：`平均应收账款 × 变动成本率 × 资金机会成本率`
8. 信用政策相关收益：`边际贡献 - 机会成本 - 坏账损失 - 收账费用 - 现金折扣成本`
9. 信用政策决策：拟议方案增量相关收益 > 0 时采纳
10. 经济订货批量：`Q* = √(2DK/Kc)`
11. EOQ 最低相关总成本：`TC = D/Q×K + Q/2×Kc`
12. 陆续供货 EOQ：`Q* = √[2DK/Kc × p/(p-d)]`
13. 陆续供货平均存货：`Q/2 × (1-d/p)`
14. 保险储备：`B = z × σd × √L`
15. 再订货点：`ROP = 平均日需求×提前期 + B`

### 7.7 成本管理

1. 单位边际贡献：`P-V`
2. 边际贡献率：`(P-V)/P`
3. 息税前利润：`EBIT = Q(P-V)-F`
4. 盈亏临界点销售量：`Q0 = F/(P-V)`
5. 盈亏临界点销售额：`F ÷ 边际贡献率`
6. 安全边际额：`实际销售额 - 保本销售额`
7. 安全边际率：`安全边际额 ÷ 实际销售额`
8. 销量敏感系数：`边际贡献/EBIT`
9. 单价敏感系数：`销售收入/EBIT`
10. 单位变动成本敏感系数：`-变动成本总额/EBIT`
11. 固定成本敏感系数：`-F/EBIT`
12. 直接材料价格差异：`实际用量×(实际单价-标准单价)`
13. 直接材料用量差异：`(实际用量-标准用量)×标准单价`
14. 直接人工工资率差异：`实际工时×(实际工资率-标准工资率)`
15. 直接人工效率差异：`(实际工时-标准工时)×标准工资率`
16. 变动制造费用耗费差异：`实际工时×(实际分配率-标准分配率)`
17. 变动制造费用效率差异：`(实际工时-标准工时)×标准分配率`
18. 固定制造费用二差异：`耗费差异=实际-预算`；`产量差异=预算-实际产量应负担额`
19. 固定制造费用三差异：`耗费差异=实际-预算`；`闲置能量差异=(预算工时-实际工时)×标准分配率`；`效率差异=(实际工时-实际产量标准工时)×标准分配率`
20. 作业成本分配率：`作业成本库 ÷ 成本动因总量`
21. 产品作业成本：`Σ(耗用动因量 × 作业分配率)`

### 7.8 证券估值

1. 债券价值：`V = 年利息×(P/A,r,n) + 面值×(P/F,r,n)`
2. 债券到期收益率：令 `V=当前价格` 解 `r`
3. 零增长股利模型：`V = D/r`
4. 有限持有期固定股利模型：`V = D×(P/A,r,n) + Pn×(P/F,r,n)`
5. 固定增长股利模型：`V = D1/(r-g) = D0(1+g)/(r-g)`，要求 `r>g`
6. 零增长股票 IRR：`r = D/P`
7. 固定增长股票 IRR：`r = D1/P + g`
8. 有限期固定股利股票 IRR：令 `P=D×(P/A,r,n)+Pn×(P/F,r,n)` 解 `r`

### 7.9 财务分析

1. 流动比率：`流动资产/流动负债`
2. 速动比率：`(流动资产-存货)/流动负债`
3. 现金比率：`货币资金/流动负债`
4. 资产负债率：`负债总额/总资产`
5. 产权比率：`负债总额/股东权益`
6. 权益乘数：`总资产/股东权益 = 1+产权比率`
7. 利息保障倍数：`EBIT/利息费用`
8. 应收账款周转率：`营业收入/平均应收账款`
9. 存货周转率：`营业成本/平均存货`
10. 流动资产周转率：`营业收入/平均流动资产`
11. 总资产周转率：`营业收入/平均总资产`
12. 营业净利率：`净利润/营业收入`
13. 总资产净利率：`净利润/平均总资产`
14. 净资产收益率：`净利润/平均股东权益`
15. 现金营运指数：`经营现金净流量 ÷ 经营所得现金`，本程序默认 `经营所得现金=净利润+折旧摊销`
16. 传统杜邦：`ROE = 营业净利率 × 总资产周转率 × 权益乘数`
17. 改进杜邦：`ROE = 净经营资产净利率 + (净经营资产净利率-税后利息率)×净财务杠杆`
18. 税后经营净利润：`净利润 + 利息费用×(1-T)`
19. 净经营资产：`净负债 + 股东权益`
20. 净经营资产净利率：`税后经营净利润/净经营资产`

### 7.10 股利分配管理

1. 剩余股利：`权益资金需求=投资预算×(1-目标负债率)`；`股利=max(净利润-权益资金需求,0)`
2. 固定/稳定增长股利：`DPS_t = DPS_0 × (1+g)^t`
3. 固定股利支付率：`股利=净利润×支付率`；`DPS=股利/股数`
4. 低正常加额外：`DPS=低正常DPS+额外DPS`
5. 股票股利：`新股数=原股数×(1+送股比例)`；`理论除权价=原市值/新股数`
6. 股票分割：`新股数=原股数×分割比例`；`理论股价=原股价/分割比例`
7. 股票回购：`回购股数=回购金额/回购价格`；`回购后EPS=净利润/剩余股数`
8. 股票股利、股票分割理论上不改变股东财富；回购提高 EPS 但减少现金与流通股

### 7.11 期权基础估值

1. 看涨期权到期价值：`max(S-K,0)`
2. 看跌期权到期价值：`max(K-S,0)`
3. 多头净损益：`到期价值-期权费`
4. 空头净损益：`期权费-到期价值`
5. 看涨盈亏平衡点：`K+期权费`
6. 看跌盈亏平衡点：`K-期权费`
7. 单期二叉树看涨价值：`Cu=max(Su-K,0)`，`Cd=max(Sd-K,0)`
8. 套期保值比率：`Δ=(Cu-Cd)/(Su-Sd)`
9. 复制组合借款：`B=(Δ×Sd-Cd)/(1+r)`
10. 期权价值：`V=Δ×S0-B`
11. 风险中性概率：`p=(1+r-d)/(u-d)`
12. 风险中性定价：`V=[p×Cu+(1-p)×Cd]/(1+r)`

### 7.12 财务预算

1. 销售预算：`预计销售收入=预计销售量×单价`
2. 生产预算：`预计生产量=预计销售量+期末产成品-期初产成品`
3. 直接材料预算：`耗用量=生产量×单位用量`；`采购量=耗用量+期末材料-期初材料`
4. 材料采购金额：`采购量×材料单价`
5. 直接人工预算：`人工工时=生产量×单位工时`；`人工成本=工时×工资率`
6. 制造费用预算：`变动制造费用=工时×分配率`；`制造费用合计=变动+固定`
7. 制造费用付现额：`制造费用合计-折旧`
8. 产品成本预算：`单位成本=单位材料+单位人工+单位变动制造费用+单位固定制造费用`
9. 现金预算：`期末现金=期初现金+销售回款-采购付款-人工-制造费用付现-销售管理费用-设备购置-所得税-股利-利息+借款-还款`
10. 最低现金约束：不足时借款至最低余额；超过最低余额时优先偿还借款
11. 销售回款：按各期回款比例对当期及以前各期销售额加权
12. 采购付款：按各期付款比例对当期及以前各期采购额加权

## 8. 计算口径与重要假设

1. **利率形式**：公式函数接收小数（`0.08`）；控制台输入百分数（`8`），程序自动转换。
2. **年金时点**：普通年金默认每期期末收付；预付年金为期初；递延年金从第 `m+1` 期期末开始。
3. **项目现金流**：初始投资单独输入并在 `t=0` 扣除；后续年度净现金流从 `t=1` 开始。
4. **IRR**：使用数值求根。非常规现金流可能存在多个 IRR，程序优先返回最小正根，并提示判断。
5. **债务贴现模式**：以税后利息和到期本金为现金流，求出税后债务资本成本，同时输出税前成本供校验。
6. **债券估值**：假设每年付息一次、到期一次还本；价格含交易价格，不含交易费用。
7. **固定股利模型**：为区分教材中的不同表述，程序将“零增长模型”用于永久持有，将“固定股利模型”用于有限持有期并含期末售价。
8. **应收账款机会成本**：默认用“平均应收账款 × 变动成本率 × 机会成本率”；若课程采用销售额口径，可将变动成本率设为 100%。
9. **Miller-Orr 模型**：程序采用 `R=L+[3Fσ²/(4i)]^(1/3)`、`H=3R-2L`，其中 `σ` 与 `i` 必须使用同一时间单位（如均为“日”）。
10. **信用政策**：采用增量相关收益法，只考虑政策变化引起的收入与成本变化。
11. **固定制造费用二差异**：`产量差异 = 预算固定制造费用 - 实际产量应负担额`；三差异将其拆为闲置能量差异和效率差异。
12. **改进杜邦**：`净经营资产=净负债+股东权益`，`税后经营净利润=净利润+税后利息`；净负债为有息负债减金融资产。
13. **现金营运指数**：默认“经营所得现金=净利润+折旧摊销”；如教材给出“经营所得现金”，可直接用该口径替换。
14. **股票股利/分割**：理论价格假设总市值不变；实际市场反应可能不同。回购分析假设净利润不变、忽略信号效应和税负。
15. **期权二叉树**：单期模型，要求 `Sd < S0(1+r) < Su`，否则不存在风险中性概率。
16. **财务预算**：期初应收/应付均在第一季度收回/支付；借款在季末发生，按季初借款余额计息；回款、付款比例可小于 100%。
17. **财务分析**：总资产、股东权益、应收账款等使用平均口径；输入时请保持金额单位一致。

> 本工具用于课程学习、作业校验和情景分析，不构成投资建议。正式决策应结合行业数据、风险因素和完整报表。

## 10. 常见问题

### Q1：图表中文显示为方框？

程序会优先注册 Windows 的微软雅黑/黑体。如仍出现方框：

1. 确认系统存在 `C:\Windows\Fonts\msyh.ttc` 或 `simhei.ttf`；
2. 删除 matplotlib 字体缓存后重启 VSCode；
3. 或在 `visual.py` 的 `candidates` 中加入本机已安装中文字体名称。

### Q2：`ModuleNotFoundError: scipy`？

```powershell
python -m pip install -r requirements.txt
```

确认 VSCode 选择的解释器与安装依赖的解释器一致。

### Q3：CSV 打开乱码？

文件使用 `utf-8-sig` 编码。若使用旧版 Excel，请用“数据 → 从文本/CSV”导入并选择 UTF-8。WPS、Office 2016 及以上通常可直接双击打开。

### Q4：输入 8 为什么变成 800%？

公式函数接收小数；控制台交互函数会自动把 8 转为 0.08。若直接调用 Python API，应传 `0.08`，而不是 `8`。

### Q5：项目 IRR 无法求解？

常见原因：

- 未来现金流全部为负，NPV 恒小于 0；
- 现金流没有发生正负号变化；
- 非常规现金流存在多个根。

程序会给出中文提示，其他指标仍可正常使用。

### Q6：现金预算为什么出现借款？

当“期初现金 + 销售回款 - 各项支出 - 利息”低于最低现金余额时，程序自动借款补足；之后有剩余现金时优先还款。可调整最低现金余额、回款比例或支出进行情景比较。

### Q7：如何清空 `result.csv`？

关闭正在运行的程序后，直接删除 `result.csv`；下次计算会自动重建表头。也可在 Python 中执行：

```python
from export import reset_result_file
reset_result_file()
```

### Q8：如何验证项目是否完整？

```powershell
python selftest.py
python selftest_ui.py
```

- `selftest.py`：12 个模块的 50 项数值断言、3 张图、CSV 单条与批量导出；
- `selftest_ui.py`：首页、12 个 GUI 页面、默认表单计算和 12 个示例计算。

### Q9：双击启动后浏览器没有打开？

手动访问 `http://localhost:8501`。如果端口被占用，可在终端改用其他端口：

```powershell
python -m streamlit run app.py --server.port 8502
```

然后访问 `http://localhost:8502`。

### Q10：如何停止本地工具？

关闭“启动财务计算器.bat”所在的命令行窗口，或在该窗口按 `Ctrl+C`。
